# SETRON 외부 서비스 정보

SETRON은 소셜 로그인 · 클라우드 저장소 · 결제 · 외부 코드 컴파일 서비스를 쓰지 않습니다. 외부 서비스는 **AI API 하나**이고, 개발 DB 이미지를 만들 때 MySQL 배포본을 한 번 내려받습니다.

> 실제 키는 이 문서와 Git에 적지 않습니다.

---

## 1. AI 모델 연결

기업 환경에서는 사내 모델 서버에 연결합니다. 같은 Chat Completions API 형식을 지원하는 상용 AI 서비스도 사용할 수 있습니다. 아래 주소와 모델명은 프로젝트에서 개발과 평가에 사용한 SSAFY GMS 설정 예시입니다.

| 항목 | 내용 |
| --- | --- |
| 용도 | ① 데이터 가져오기: 규칙으로 읽지 못하는 Excel 양식의 AI 추출 ② AI 분석: 자연어 질문을 조건(사업장 · 라인 · 설비군 · 기준 등)으로 해석 · 답변 문장 |
| 방식 | OpenAI 호환 Chat API. 앱은 `openai` Python SDK에 `base_url`만 바꿔 호출 (`src/setron/infrastructure/ai_client.py`의 `OpenAICompatibleChatClient`) |
| 개발 예시 주소 | `https://gms.ssafy.io/gmsapi/api.openai.com/v1` |
| GMS 키 발급 | SSAFY 계정으로 GMS(`https://gms.ssafy.io`)에 로그인해 API Key 발급 |
| 참고 문서 | GMS 가이드 `https://gms.ssafy.io/web/guide/quickstart` (OpenAI 경로), OpenAI Python SDK `base_url` 설정 |
| 모델 | `gpt-6.1-sol` (개발 · 교육 자료 평가에 사용, `.env.example`과 같음). GMS에서 사용 가능한 모델로 바꿔 쓸 수 있음 |

### 설정 방법

`.env`(개발) 또는 `setron.env`(실행 파일)에 입력합니다.

```
SETRON_AI_BASE_URL=https://gms.ssafy.io/gmsapi/api.openai.com/v1
SETRON_AI_API_KEY=<발급받은 키>
SETRON_AI_MODEL=gpt-6.1-sol
SETRON_AI_TIMEOUT=180
```

- 키가 없거나 설정을 비우면 앱은 예제 응답으로 동작합니다. 다른 `OPENAI_*` 설정이나 기본 OpenAI 서버로 대체하지 않습니다.
- **회사 환경으로 옮길 때**: 기업 제약 조건에 따라 사내 OpenAI 호환 서버를 씁니다. 같은 네 항목에 사내 서버 주소(`/v1`까지) · 키 · 모델명만 바꾸면 코드 수정 없이 전환됩니다(`setron.env.example`의 `gpt-4`는 사내 예제 모델명).
- AI가 읽은 값은 원본 Excel 칸과 대조한 뒤 사람이 검토해야 저장되고, AI 분석의 숫자는 DB가 계산합니다. AI 응답이 달라져도 저장 자료 · 집계 숫자는 바뀌지 않습니다.

## 2. MySQL 5.6.19 배포본 (개발 DB 이미지 빌드 시)

| 항목 | 내용 |
| --- | --- |
| 용도 | Docker 개발 · 테스트 DB 이미지 `setron/mysql:5.6.19` 빌드 (`mysql:5.6.19` 공식 Docker 태그가 없음) |
| 주소 | `https://cdn.mysql.com/archives/mysql-5.6/mysql-5.6.19-linux-glibc2.5-x86_64.tar.gz` |
| 가입 | 필요 없음 (Oracle 공개 보관소) |
| 비고 | 최초 `docker compose build mysql-dev`에서 한 번 내려받음(약 306MB). Dockerfile이 체크섬과 서버 버전을 확인 |

실사용 PC는 Windows용 공식 ZIP(`mysql-5.6.19-winx64.zip`)을 설치해 사용합니다.

## 3. 개발 도구 (가입 불필요)

| 도구 | 용도 |
| --- | --- |
| Docker Desktop | 개발 · 테스트 MySQL 컨테이너 실행 (Linux 엔진) |
| uv | Python 패키지 설치 · 실행 (`uv.lock`) |

| Microsoft Excel (데스크톱) | 데이터 가져오기 원본 (열린 통합문서에서 읽음) |
